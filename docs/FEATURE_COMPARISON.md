# Features retained and added

Retained: departments, subjects, faculty workload, divisions/batches, room eligibility, optional mini projects, college timing controls, CSV/Excel/JSON exchange, scoped generation, manual edits, workflow states, saved-version deletion, separate batch cards, all room/professor views, exports, analytics, local chat and optional OpenAI explanations.

Added in this update: official source CSV loading, tutorial assignments with fixed rooms, an independent Tutorials editor, per-generation start choice, and enforced two/three-period lecture classroom continuity. No data is manufactured to resolve capacity shortages. See README.md for the supplied data's limitations.
